# 地图底图目录

本目录存放《长征征途》使用的**本地矢量底图**。作品**不复用来源不明的在线底图，也不做静默在线回退**，这样做的目的是保证地图的领土表示始终可控、可核。

## 文件清单

| 文件 | 是否必需 | 作用 |
| --- | --- | --- |
| `china.json` | **必需** | 中国省级行政区划矢量底图（GeoJSON，`FeatureCollection`），地图主体 |
| `nanhai.json` | 可选 | 当主底图缺少“南海诸岛 / 九段线”等法定表示要素时，用于补充该要素 |
| `sources.json` | 建议 | 底图来源声明，界面“资料来源与注记”会原样展示 |

## 底图合规要求（重要）

对标赛事“无领土争议问题”要求，入库底图必须满足：

1. **完整包含法定表示内容**：台湾省、海南省（含南海诸岛）以及九段线表示不得遗漏、不得裁切。
2. **不得修改边界**：不得对底图边界线、岛屿、海岸线做任何增删或简化到失真。
3. **用于正式参赛或公开出版时**，应以**自然资源部标准地图服务网站**（<http://bzdt.ch.mnr.gov.cn/>）发布的、**带审图号**的标准地图为准，并在地图或作品说明中按要求标注审图号。
4. 若使用第三方开源矢量数据，须在其许可范围内使用，并在 `sources.json` 中如实注明提供方与来源地址。

> 本作品在界面中设有**底图自检**：加载后会检测底图要素中是否出现“南海诸岛”等关键字。若未检测到，会自动尝试加载 `nanhai.json`；仍然缺失时，界面会显示明确的告警，提示更换合规底图，**不会静默展示一张不完整的地图**。

## GeoJSON 结构要求

```json
{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "properties": { "name": "北京市", "adcode": 110000 },
      "geometry": { "type": "Polygon", "coordinates": [[[116.2, 39.9], "..."]] }
    }
  ]
}
```

- `properties.name` 为省级行政区名称，用于底图自检与地名展示。
- `geometry` 建议为 `Polygon` 或 `MultiPolygon`；经纬度为 WGS84（`[经度, 纬度]`）。
- 主底图建议包含**完整的南海诸岛插图**（通常是位于图幅右下角的一组坐标范围，构成“南海诸岛”要素）。

## 关于内置获取脚本（`scripts/fetch-basemap.mjs`）

仓库提供了底图获取脚本，用于**本地开发预览**：

```bash
pnpm fetch:basemap                        # 依次尝试内置候选源
pnpm fetch:basemap --url <地址>            # 指定来源
pnpm fetch:basemap --strict               # 未通过合规自检时以退出码 1 结束
```

脚本会下载并校验 GeoJSON、**不简化不裁剪任何坐标**、原样写入 `china.json`，同步更新 `sources.json`，并打印合规检查清单。

> ⚠ **内置候选源不能用于正式参赛。** ECharts 4.x 内置的 `china.json` 只包含南海诸岛插图、**缺少九段线线段**（apache/echarts 有相关已知问题）；DataV 数据以行政区划为主，南海诸岛与九段线的表达需自行核对。脚本会在输出中明确标注每个来源的已知问题，并在客观检测项（南海诸岛插图、九段线）任一未通过时，明确给出「不满足赛事使用条件」的结论——**不会把预览用底图判定为合规**。

## 如何放置底图

1. 获取一份满足上述合规要求的中国省级矢量 GeoJSON。
2. 命名为 `china.json` 并放入本目录。
3. 按下方模板填写 `sources.json`。
4. 刷新页面；若界面出现“未检测到南海诸岛要素”的告警，请更换底图或补充 `nanhai.json`。

## sources.json 模板

```json
{
  "id": "cn-provinces",
  "description": "中国省级行政区划矢量底图（GeoJSON），用于本作品地图渲染。",
  "publisher": "数据提供方名称",
  "url": "来源地址",
  "obtainedAt": "2025-01-01",
  "license": "许可协议名称",
  "standardMapNote": "本底图未对任何边界作修改。如用于正式参赛或公开出版，请以自然资源部标准地图服务网站发布的带审图号标准地图为准。"
}
```
