# public/symbols —— 标识素材目录

这个目录用于放置**官方标准标识素材**。

## 为什么需要它

页面里的标识分两类，使用规范不同：

| 标识 | 当前实现 | 规范要求 |
| --- | --- | --- |
| **中华人民共和国国旗**（五星红旗） | `src/components/FlagCN.vue`，**按标准规格用几何方式精确绘制**（旗面 3:2；大星中心 (5,5) 半径 3；四小星中心 (10,2)、(12,4)、(12,7)、(10,9) 半径 1；各有一角正对大星中心） | 《中华人民共和国国旗法》要求国旗按规定的规格制作，**比例与星位不得随意改动**。本组件的绘制符合规格，可直接使用 |
| **中国共产党党徽**（镰刀和锤头） | `src/components/PartyEmblem.vue`，**几何化简化示意** | 《中国共产党党徽党旗条例》要求党徽按规定的标准图案使用。当前组件是示意性绘制，**比例与官方标准图并不完全一致** |

## 正式提交前请替换党徽

1. 从权威渠道获取**官方标准党徽矢量图**（中国政府网、共产党员网等）；
2. 保存为 `public/symbols/party-emblem.svg`；
3. 修改 `src/components/PartyEmblem.vue`，把内联 SVG 换成：

```vue
<template>
  <img class="emblem" src="/symbols/party-emblem.svg" alt="中国共产党党徽" />
</template>

<style scoped>
.emblem {
  display: block;
  width: 100%;
  height: 100%;
}
</style>
```

这样使用处的红底、尺寸、圆角都不需要改动。

## 使用原则

本作品对标识的使用遵循「**适度、规范、不娱乐化**」：

- **不滥用**：全站只在两处出现——顶部导航的品牌标识（国旗）、「长征精神」页的页首（党徽）；
- **不变形**：国旗严格保持 3:2，党徽保持等比缩放，不拉伸、不旋转、不加特效；
- **不商用**：本作品为非商业性科普作品，标识不用于商标、广告等《国旗法》《党徽党旗条例》禁止的用途；
- **不覆盖**：标识为纯展示，不叠加文字、不加滤镜、不做动效。
