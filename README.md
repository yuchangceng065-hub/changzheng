# 长征征途 · 使用说明

源码下载后需要安装 Node.js 才能运行。直接使用 Windows 免安装版，请到 [GitHub Releases 下载页](https://github.com/yuchangceng065-hub/changzheng/releases/latest) 下载运行包；完整交付包还包含代码文件、第三方资源说明和修改记录。

## Mac 免安装版

如已取得 Mac 免安装包，可直接使用。GitHub 当前发布的免安装程序为 Windows 版，Mac 可按下一节从源码启动。Mac 免安装包适用于 macOS 13 或更新版本，支持 M 系列和 Intel 芯片。完整解压后双击 `启动长征征途.command`，无需安装依赖。使用时保留终端窗口，按 `Ctrl+C` 或关闭窗口停止网站。

首次打开如遇系统拦截，请查看包内的使用说明。

## 在 Mac 上打开

1. 首次使用先安装 [Node.js LTS](https://nodejs.org/zh-cn)，建议 22.12 或更新版本。
2. 双击项目里的 `启动网站.command`。首次启动会联网安装依赖，并自动打开浏览器。
3. 使用期间保留启动窗口。停止网站时按 `Ctrl+C`，或关闭该窗口。

再次双击会打开已运行的网站。默认地址是 `http://127.0.0.1:5173/`；端口被其他程序使用时，会自动换到后续端口，以启动窗口显示的地址为准。

也可以在项目文件夹打开终端，运行 `npm start`。Windows 用户双击 `run.cmd`。

## 浏览网站

- 首页：选择部队，或直接进入重要事件。
- 部队介绍：查看部队沿革和长征概况。
- 探索地图：点击地图节点或下方时间线阅读事件；点击节点图片可放大。可播放路线、调整速度、拖动和缩放地图。
- 长征图集：查看全部图片，按部队筛选或搜索。点击图片后可放大、缩小或查看原图，按 Esc 关闭。
- 长征精神：观看邱潇讲授的“党史启迪未来”系列短视频《长征精神》，阅读内容提要、专题和参考资料。视频随包保存，可离线播放；播放时背景音乐暂停。
- 留言墙：点击顶部导航入口，从右侧打开留言抽屉，保存在当前浏览器，可删除或清空。
- 右侧音乐悬浮球：拖动圆心可移动位置，点击播放或暂停，鼠标悬停显示进度与音量条。打开网页时尝试自动播放；浏览器阻止时，首次点击页面后播放。背景音乐为《崇高理想》—红红肖，默认音量10%。

地图按地点标注，节点间连线用于路线示意。

首页已删除长征影像区域。背景音乐已接入团队提供的《崇高理想》—红红肖，原文件标注来自爱给网；曲名、署名及来源记录见src/data/music.js。

实际互动底图已更换为天地图行政区划可视化服务的全国数据，该服务标注数据更新时间为2026年10月。public/map/china.json保存接口返回的完整GeoJSON，包含34个省级行政区划和8组境界线，不再使用旧DataV底图。

已取消ECharts自动补绘的南海小框，实际底图原有岛屿和境界线完整保留。地形背景仍为Natural Earth。地图初始取景已减少留白，部队选择卡片在左栏居中。来源与文件校验值见public/map/sources.json。地图栏注明天地图在线底图审图号GS（2026）4921号，来源链接保留。天地图页面在线底图的审图号不转用于本项目本地矢量数据或叠加地图。

## 修改文字和图片

- 部队介绍、事件正文、地图点位：`src/data/armies.js`。
- 节点图片：`public/art/`；图片与节点的对应关系、图名和来源：`public/art/manifest.json`。
- 首页封面：`public/images/long-march-cover.png`。
- 长征精神视频：`public/video/党史启迪未来-长征精神-邱潇.mp4`；标题、讲师、提要和来源：`src/data/spiritVideo.js`。
- 音乐：将已取得使用许可的曲目放到 `public/music/`，在 `src/data/music.js` 的 `src` 填写 `music/文件名.mp3`，再重新打包。
- 图注的 `title` 只写图名，`sourceLabel` 写“来源：机构名”，`source` 填原发布页链接。没有来源时可省略后两项。

## 构建和排查

- 生成发布文件：`npm run build`，结果在 `dist/`。
- 检查数据与图片引用：`npm run check:data`。
- 提示找不到 Node：安装 Node.js LTS 后重新打开启动窗口。
- 依赖安装失败：检查网络后重新启动；依赖损坏时在项目终端运行 `npm ci`。
- 不能直接双击 `index.html` 浏览网站，请通过启动入口打开。
