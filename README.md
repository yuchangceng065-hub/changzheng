# 长征征途 · 项目介绍与源码说明

## 一、项目简介

**长征征途**是一个以中国工农红军长征历史为主题的交互式可视化网站，旨在通过地图展示、历史事件介绍、多媒体资源和互动功能，让用户更加直观地了解红军长征的历史过程及长征精神。

项目将历史资料与现代 Web 前端技术相结合，以不同红军部队的长征历程为主线，通过交互式地图、时间线、历史图片和专题视频等形式，呈现长征中的重要事件、行军路线及相关历史背景。

网站支持 Windows 和 macOS 系统，可通过源码启动，也可使用打包后的免安装程序运行。

## 二、项目主要功能

### 1. 首页展示

首页作为网站入口，提供长征主题介绍和部队选择功能。用户可以选择不同部队，进入相应的历史内容和地图页面，也可以直接浏览重要历史事件。

### 2. 部队介绍

展示不同红军部队的历史沿革、长征背景和主要经历，帮助用户了解各支部队在长征中的作用。

相关数据保存在 `src/data/armies.js` 中，便于后期修改和补充。

### 3. 交互式长征地图

地图是项目的核心功能之一，主要包括：

- 展示中国地图及长征相关历史地点。
- 根据部队展示对应的长征路线。
- 点击地图节点查看历史事件。
- 通过时间线按顺序浏览事件。
- 支持路线动态播放和播放速度调整。
- 支持地图缩放、拖动和图片放大查看。

项目使用 ECharts 实现地图交互，地图节点和路线数据与历史事件内容相结合，使历史信息能够以更加直观的形式呈现。

行政区划矢量数据采用天地图行政区划可视化服务提供的数据，保存在 `public/map/china.json` 中。地形背景使用 Natural Earth 数据。

地图路线属于历史路线的可视化示意，并非精确地理轨迹。

### 4. 长征图集

集中展示项目收录的长征历史图片，支持按部队筛选、关键词搜索、图片放大缩小及查看原图等操作。

图片统一保存在 `public/art/` 目录中，相关图片标题、来源和对应关系记录在 `public/art/manifest.json` 中，方便后期维护。

### 5. 长征精神专题

通过视频与文字相结合的方式介绍长征精神。

项目收录了邱潇讲授的“党史启迪未来”系列短视频《长征精神》，并提供相关内容提要、专题和参考资料。

视频文件保存在项目本地，支持离线播放。

### 6. 留言墙

提供浏览器端留言功能，用户可以输入、查看和删除留言。

留言保存在当前浏览器中，无需额外部署数据库或服务器端留言系统。

### 7. 背景音乐

网站集成了背景音乐播放功能，支持播放暂停、音量调整和播放进度查看。

音乐播放器采用悬浮球形式，可以通过拖动调整位置。

默认背景音乐为《崇高理想》—红红肖，相关配置保存在 `src/data/music.js` 中。

## 三、项目代码结构

项目主要采用前端代码、数据文件与静态资源分离的组织方式，以便于修改和维护。

以下列出主要文件及目录：

```text
changzheng/
│
├── src/
│   └── data/
│       ├── armies.js          # 部队、事件及路线数据
│       ├── music.js           # 背景音乐配置
│       └── spiritVideo.js     # 长征精神视频信息
│
├── public/
│   ├── art/
│   │   ├── manifest.json      # 图片索引及来源信息
│   │   └── ...                # 历史图片资源
│   │
│   ├── images/
│   │   └── long-march-cover.png
│   │
│   ├── map/
│   │   ├── china.json         # 中国行政区划GeoJSON
│   │   └── sources.json       # 地图来源与文件校验信息
│   │
│   ├── music/                 # 背景音乐文件
│   │
│   └── video/
│       └── 党史启迪未来-长征精神-邱潇.mp4
│
├── index.html                 # 网页入口
├── package.json               # 项目依赖及运行脚本
├── run.cmd                    # Windows源码启动入口
├── 启动网站.command           # macOS源码启动入口
└── dist/                      # 构建后生成的文件
```

注：以上为主要文件结构，完整组件、样式及其他配置文件以实际源码为准，`dist/` 需执行构建命令后生成。

## 四、核心代码说明

### 1. 历史数据管理

`src/data/armies.js` 是项目的重要数据文件，主要用于组织不同部队的介绍、历史事件及地图位置等信息。

网站中的部队介绍、地图节点和事件内容均与该文件中的数据相关。

通过将历史资料与页面展示逻辑分离，可以在不大幅修改前端功能代码的情况下，对历史内容进行更新。

### 2. 地图数据与可视化

地图采用 GeoJSON 格式的行政区划数据，结合 ECharts 实现地图显示与交互。

主要涉及以下内容：

- 加载中国行政区划矢量数据。
- 根据历史事件数据标注地图节点。
- 根据节点顺序绘制长征路线。
- 实现节点点击、路线播放与地图缩放等交互。
- 将地图节点与时间线、事件详情进行关联。

其中，`public/map/china.json` 保存行政区划数据，`public/map/sources.json` 记录数据来源及校验信息。

### 3. 图片资源管理

图片资源统一存放在 `public/art/` 中，通过 `manifest.json` 管理图片信息。

图片元数据包括：

- 图片标题 `title`
- 来源机构 `sourceLabel`
- 原始来源链接 `source`

这种组织方式可以减少图片信息分散在页面代码中的情况，便于替换图片、补充来源及维护历史资料。

### 4. 视频模块

长征精神专题的视频文件保存在 `public/video/` 中，视频标题、讲师、简介和来源等信息由 `src/data/spiritVideo.js` 管理。

视频资源随项目一起打包，因此无需依赖在线视频地址即可播放。

### 5. 音乐模块

音乐信息集中在 `src/data/music.js` 中维护，包括音乐文件路径及相关署名信息。

播放器实现了音乐播放控制、进度展示、音量调节及位置拖动功能。

为适应浏览器自动播放限制，若首次进入页面时音乐无法自动播放，用户可以通过首次页面交互触发播放。

## 五、源码运行方法

### 1. 环境要求

开发或从源码运行项目需要安装：

- Node.js LTS，建议 22.12 或更新版本
- npm（随 Node.js 安装）

Node.js 官网：https://nodejs.org/zh-cn

安装完成后，在终端执行：

```bash
node -v
npm -v
```

如果能够正确显示版本号，说明运行环境已准备好。

### 2. 启动项目

下载并解压源码，在项目根目录打开终端，执行：

```bash
npm install
npm start
```

首次启动需要联网安装依赖，后续可直接启动。

网站默认访问地址：

```text
http://127.0.0.1:5173/
```

如端口被占用，请以终端实际显示的地址为准。

Windows 用户也可以双击 `run.cmd`。

macOS 用户可以双击 `启动网站.command`。

### 3. 构建项目

执行：

```bash
npm run build
```

构建后的文件生成在 `dist/` 目录中。

### 4. 数据检查

执行：

```bash
npm run check:data
```

用于检查项目数据与图片引用。

## 六、代码修改与二次开发

项目将历史内容与静态资源相对集中地管理，便于根据需求进行二次开发。

| 修改内容 | 对应文件或目录 |
|---|---|
| 部队介绍、历史事件、地图节点 | `src/data/armies.js` |
| 长征历史图片 | `public/art/` |
| 图片标题及来源 | `public/art/manifest.json` |
| 首页封面 | `public/images/long-march-cover.png` |
| 行政区划地图数据 | `public/map/china.json` |
| 地图来源与校验信息 | `public/map/sources.json` |
| 长征精神专题信息 | `src/data/spiritVideo.js` |
| 长征精神视频 | `public/video/` |
| 音乐信息 | `src/data/music.js` |
| 音乐文件 | `public/music/` |

修改完成后，可以重新启动项目进行测试，并使用 `npm run build` 生成新的发布文件。

如果需要添加新的部队或历史事件，应根据 `armies.js` 中已有数据格式进行扩展，并检查地图节点、图片文件和时间线内容是否匹配。

## 七、免安装版本

为方便不熟悉开发环境的用户使用，项目提供了免安装运行方案。

**Windows 版本**

访问 [GitHub Releases](https://github.com/yuchangceng065-hub/changzheng/releases/latest) 下载 Windows 运行包。

完整解压后，双击 `启动长征征途.exe` 即可启动网站。

支持 Windows 10 / 11 64 位系统，无需另外安装 Node.js。

**macOS 版本**

Mac 免安装包支持 macOS 13 及以上版本，兼容 Apple Silicon 和 Intel 芯片。

取得完整运行包后，双击 `启动长征征途.command` 即可启动，不需要安装额外依赖。

目前 GitHub Releases 发布的是 Windows 免安装程序，Mac 用户也可以按照前文通过源码运行。

**重新制作运行包**

在对应系统的打包环境中执行：

```bash
# Windows运行包
npm run package:windows

# macOS运行包
npm run package:mac
```

打包 Windows 版本需要 Go；打包 macOS 版本需要 Go 和 Apple Command Line Tools。

这些工具只在制作运行包时需要，最终使用者无需安装。

## 八、项目特点

本项目的主要特点包括：

1. **历史内容可视化**：利用地图和时间线，将长征过程中的地点、事件与行军路线联系起来。
2. **多种交互方式**：结合地图节点、图片浏览、动态路线播放和专题视频，提高网站的互动性。
3. **数据与页面分离**：将主要历史数据、图片信息和多媒体配置单独管理，便于后期维护和扩展。
4. **支持离线使用**：主要图片、地图数据和视频资源保存在本地，打包后可在无网络环境下浏览核心内容。
5. **跨平台运行**：支持在 Windows 和 macOS 上通过源码或对应运行包启动。

## 九、资源来源与使用说明

项目中使用的历史图片、地图、音乐和视频资源均保留相应来源信息，具体可参考对应数据文件。

地图行政区划数据来自天地图行政区划可视化服务，相关数据文件保存于 `public/map/china.json`，来源及校验信息记录在 `public/map/sources.json` 中。

地图页面保留了天地图在线底图相关来源及审图号信息，但在线底图的审图号不代表本项目本地矢量数据或叠加地图已经获得相同审图批准。

地形背景使用 Natural Earth 相关数据。

项目中的第三方图片、音乐和视频不因包含在源码或运行包中而自动获得开放使用许可。传播、修改或用于其他用途时，应遵守对应资源的版权及授权要求。
