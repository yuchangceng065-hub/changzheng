# 配图清单与操作说明

> 本作品共 56 个历史节点。**只圈定 13 个最值得配真实照片的节点**，其余 43 个保持手绘插画即可——插画按事件类型自动匹配，本身已经是完整的呈现。

---

## 一、为什么只挑这 13 个

三个考虑：

1. **认知度**：遵义会议、泸定桥、过草地这类节点，观众一看照片就能对上史实；
2. **画面感**：有明确地标（铁索桥、雪山、会师纪念塔），照片拍得出东西；
3. **部队均衡**：四路红军都要有代表，不能只有中央红军有图。

清单已按 `必备 8 + 建议 5` 分级写进 [`public/art/manifest.json`](../public/art/manifest.json)，你可以先做必备的 8 张，其余有空再补。

## 三、操作步骤（3 步）

**第 1 步：放图**

把图片按上表的文件名放进 `public/art/`，例如 `public/art/r1-zunyi.jpg`。

- 格式：`.jpg` 最合适；`.png`、`.webp` 也可以（改 `file` 字段的扩展名即可）
- 尺寸：宽度 ≥ 640px；显示区约 16:9，**横构图**最合适
- 体积：单张建议 300KB 以内

**第 2 步：填出处**

打开 `public/art/manifest.json`，找到对应节点，把那四项填上：

```json
"r1-zunyi": {
  "file": "r1-zunyi.jpg",
  "reviewed": false,
  "title": "遵义会议会址",
  "author": "新华社 / 遵义会议纪念馆",
  "license": "图片来源：遵义会议纪念馆官网（教育用途）",
  "source": "https://www.zunyihuiyi.com/",
  ...
}
```

**第 3 步：翻开关**

把 `"reviewed": false` 改成 `"reviewed": true`。刷新页面，插画就换成照片了，题注会自动显示作者与许可。

## 四、出处怎么填（这一项不能省）

赛事对图片注记有要求，而且**填清楚出处也是在保护你自己**。四项的含义：

| 字段 | 填什么 | 示例 |
| --- | --- | --- |
| `title` | 这张照片拍的是什么 | `泸定桥（2021 年摄）` |
| `author` | 摄影者或提供机构 | `某某 / 泸定桥革命文物陈列馆` |
| `license` | 授权情况；**不确定就如实写明来源与用途**，不要留空 | `来源：纪念馆官网，教育科普用途` |
| `source` | 原始页面链接 | `https://…` |

**如果确实查不到授权信息**，就老实写"来源：XX 官网，用于教育科普"，不要写"CC BY"之类你没核实过的许可。**宁可写得不漂亮，也不要写假的。**

---

## 五、找不到照片怎么办

**完全可以不放。** 这不是缺陷：

- 缺图的节点会自动使用手绘插画，画面是完整的；
- 界面右上角会明确标注这张配图是**「史料图片」**还是**「手绘插画」**——观众不会误以为手绘是史料；
- 一张出处清楚的照片，胜过五张来路不明的。

所以：**能拿到几张就配几张**，按必备优先，做不完也不影响作品完整。

---

## 六、一条容易踩的坑

**不要把现今拍摄的照片标成"1935 年历史照片"。**

你手上大概率能找到的是**现今实地的照片**（今天的泸定桥、今天的遵义会议会址）。这完全可用，而且对地图类科普作品来说更贴切——但 `title` 必须如实写：

- ✅ `泸定桥（2021 年摄）`
- ❌ `泸定桥（1935 年）`

把现今照片标成历史影像，就是伪造史料。这条线比"配图好不好看"重要得多。
